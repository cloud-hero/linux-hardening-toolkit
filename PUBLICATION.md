# Public toolkit distribution · LH-1.3

This repository is the curated toolkit built and validated in the CloudHero Linux hardening workspace. LH-1.3 separates three tasks: evidence-only assessment in the primary guide/PDF; separately approved changes in `hardening-runbook.md`; optional disposable-VM provisioning and test reproduction in `lab-guide.md`. Package installation is never an assessment prerequisite. Missing tools or observations remain evidence gaps, and the prompt must not install or repair them. Mixed inspection/change examples in the runbook now use separate blocks.

The required workflow remains operator collection on the server, redaction and approved transfer, then prompt-based analysis on a different machine against supplied evidence. The prompt forbids automatic download/execution, server access and workstation inspection. Collection, inventory, report and VM-fixture implementations and the LH-1.2 control catalogue are unchanged. The GRUB regression now reads the moved runbook; its assertions are unchanged.

The source website and VM runtime are not part of this repository. No VM disks, private keys, credentials, raw application logs, local browser screenshots or runtime state are included. Historical transcripts describe a disposable lab; usernames, private-range lab addresses, kernel versions and timestamps are lab observations, not production targets or current package recommendations.

`evidence/source-sha256.txt` is the original build's historical source manifest. It includes builder files outside this curated distribution and is not a checksum list for the public repository. Root `SHA256SUMS` instead covers this published distribution, excluding itself. Release `SHA256SUMS` covers the downloadable ZIP, PDF and prompt. Hashes provide integrity checks, not independent author attestation.

The PDF is the rebuilt, visually reviewed 19-page LH-1.3 assessment edition. Previous releases and their original assets remain available. This documentation/prompt update does not claim another VM test run or guarantee model behavior; the operator must enforce the stated execution boundary. Markdown download links are adjusted for browsing on GitHub; that does not alter operational guidance. Root tools and their `scripts/` copies must stay identical; the validation command checks this. The `content/` copies support the fixture tests, with assessment-guide links normalized for their directory. The separate runbook retains the tested executable guidance.

Historical review records describe the state at review time, including “no push or deployment” and the previously unavailable interactive-browser recheck. Publishing this toolkit supersedes only that repository-publication status. It does not deploy the article to the CloudHero website or claim another VM test run. The LH-1.3 local page was freshly inspected in Chrome through native app controls; the browser-extension host was unavailable.

Run `python3 scripts/validate-toolkit.py` before proposing a change. Regenerate checksums for an intentional release and rerun the disposable-VM exercises whenever executable hardening guidance changes. Keep customer evidence and collection outputs outside Git.

Local release validation includes the existing inventory/report/guide fixture suites, the packaged ZIP, all 28 catalogue IDs, report evidence references, checksums, HTTP page/content checks and rendered PDF review. Normal workstation runs retain the root-only capture-test skip; the dated VM receipt is not relabelled as a new run.
