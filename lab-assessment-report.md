## Prioritized handoff — all production changes NOT RUN

1. **Service/network owner:** complete the exposure inventory and authorized external IPv4/IPv6/UDP evidence before production acceptance. Dependency: approved source/destination scope and independent recovery access. Preserve exact host/cloud rules for rollback; repeat positive and negative probes after any change.
2. **Security/observability owner:** demonstrate both event streams at the production receiver, a rejected peer identity, outage detection/recovery and a routed alert with human acknowledgement before accepting the detection controls. Preserve prior forwarding configuration; verify no gaps after rollback. Set delivery, retention and acknowledgement deadlines in the policy.
3. **Platform and service owners:** approve patch/support/deadline policy, actual transaction/job/dependency acceptance, canary thresholds and recovery objectives before maintenance. Review the exact package transaction and test rollback; returning to an old kernel reopens vulnerability triage. Repeat the same OS and workload checks after reboot.
4. **Configuration/identity owners:** supply independent baseline provenance, runtime/package comparisons and access reviews before approving the baseline. Investigate unexplained drift before reconciliation; do not regenerate a manifest to hide a mismatch. Exceptions need owner, approver, compensating control and expiry.
