ISSUES FOUND AND ADDRESSED
1. After an OpenSSH update, ssh.socket was listening but ssh.service was idle.
   sshd -t reported missing /run/sshd until a fresh real connection activated
   the service and recreated RuntimeDirectory. The guide documents this.
2. ausearch defaults to stdin when input is redirected. The lab harness now
   explicitly uses --input-logs, with a bounded wait for event completion.
3. apt-get upgrade kept back kernel meta-packages requiring new dependencies.
   needrestart initially reported the old running kernel as up to date because
   the newer image was not installed. The guide now includes candidate checks,
   a reviewed --with-new-pkgs simulation and actual post-reboot verification.
4. Lima stop/start regenerated cloud-init instance identity and SSH host keys.
   The new lab key was checked against the managed guest's regenerated public
   key before refreshing the task-only trust file. The subsequent guest reboot
   preserved it. No production known_hosts files were changed.
